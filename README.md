# 📝 LifeStyle & News Blog

Современный блог для публикации новостей и лайфстайл-контента. Проект разворачивается в облачной инфраструктуре Yandex Cloud с использованием методологии Infrastructure as Code (IaC) и автоматизированного CI/CD пайплайна.

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3 (включая `normalize.css`)
* **Backend:** Python, FastAPI, PostgreSQL
* **Контейнеризация:** Docker, Docker Compose (мультиконтейнерная архитектура)
* **Инфраструктура (IaC):** Terraform (провайдер Yandex Cloud)
* **Конфигурация:** Ansible (автоматическая установка Nginx, деплой фронтенда)
* **Автоматизация:** CI/CD пайплайн (тестирование, сборка и деплой в прод)

## 📌 План разработки и Чек-лист проекта

### 1. Инфраструктура и автоматизация (IaC)
- [ ] **Проектирование инфраструктуры в Terraform**
  - [ ] Получение сервисного ключа от Yandex Cloud
  - [ ] `providers.tf` — настройка зеркала провайдера и авторизации
  - [ ] `variables.tf` — описание конфигурационных переменных
  - [ ] `terraform.tfvars` — заполнение конфиденциальных параметров и значений
  - [ ] `main.tf` — декларативное описание вычислительных ресурсов (VPS, сети)
  - [ ] `output.tf` — вывод публичного IP и данных после создания инфры
- [ ] **Автоматизация настройки сервера через Ansible**
  - [ ] `inventory.yml` — конфигурация хостов и доступов для SSH-подключения
  - [ ] `playbook.yml` — сценарий установки зависимостей (Docker, Docker Compose) и настройки Nginx
  - [ ] `backend` — развертывание связки контейнеров приложений

### 2. Разработка Frontend
- [ ] `index.html` — верстка базового каркаса новостного блога
- [ ] `style/` — директория со стилями оформления
  - [ ] `style.css` — кастомные стили, сетка и адаптивный дизайн
  - [ ] `normalize.css` — сброс дефолтных стилей браузеров
- [ ] `img/` — папка со статическими изображениями и медиа-файлами

### 3. Разработка Backend
- [ ] **Бизнес-логика на FastAPI**
  - [ ] Проектирование API-эндпоинтов для постов, новостей и категорий
  - [ ] Интеграция ORM (SQLAlchemy/SQLModel) для работы с БД
- [ ] **База данных PostgreSQL**
  - [ ] Разработка реляционной схемы данных (таблицы пользователей, новостей)
  - [ ] Настройка миграций

### 4. Контейнеризация (Docker)
- [ ] `docker-compose.yml` — оркестрация многоконтейнерного приложения (`frontend`, `backend`, `db`)
- [ ] `Dockerfile` (для backend-сервиса на Python)
- [ ] `Dockerfile` (для frontend-статического сервиса / Nginx)

### 5. Непрерывная интеграция и деплой (CI/CD)
- [ ] `.gitlab-ci.yml` — описание этапов linting/testing, сборки docker-образов и деплоя на прод-сервер

## 🚀 Как запустить локально

### Предварительные требования
Убедитесь, что у вас установлены **Docker** и **Docker Compose**.

### Шаги для запуска
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/S6ade/terminal-life.git
   cd terminal-life
   ```
2. Поднимите Docker-контейнеры:
   ```bash
   docker-compose up -d --build
   ```
3. Откройте приложение в браузере:
   * Фронтенд: `http://localhost`
   * Документация API (Swagger): `http://localhost:8000/docs`
